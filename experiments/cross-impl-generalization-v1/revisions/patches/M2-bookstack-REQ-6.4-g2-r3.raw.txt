## Analysis

The error is clear: `InvalidSelectorError: Error while parsing selector 'link[name=[object Object]]'`. This occurs because `byRole('link', { name: title, exact: true })` is being passed an object instead of a string for the `name` parameter in some cases.

Looking at the code in `operations.ts`, the issue is in the `openPage` function:

```ts
const pageEntry = await resolve(scope, `page entry ${title}`, [
  byRole('link', { name: title, exact: true }),
  byRole('button', { name: title, exact: true }),
]);
```

The `byRole` function expects the second parameter to be either a `RegExp` or a `string`, but here it's receiving an object `{ name: title, exact: true }`. The `byRole` function signature is:

```ts
export const byRole = (role: Parameters<Page['getByRole']>[0], name: RegExp | string, exact = true): Candidate => ({
  how: `${role}:${name}`,
  loc: s => s.getByRole(role, typeof name === 'string' ? { name, exact } : { name }),
});
```

When an object is passed as `name`, it gets stringified to `[object Object]` in the `how` field, and then Playwright tries to parse it as a selector, causing the error.

The fix is to pass the `title` string directly to `byRole`, and let `byRole` handle the options.

Additionally, I need to check the `listEntries` function in `observe.ts` which also uses `byRole` with an object:

```ts
const l = scope.getByRole('link', { name: title, exact: true }).or(scope.getByRole('button', { name: title, exact: true }));
```

This is correct because it's calling `getByRole` directly, not using the `byRole` helper.

So the main fix is in `operations.ts` in the `openPage` function.
