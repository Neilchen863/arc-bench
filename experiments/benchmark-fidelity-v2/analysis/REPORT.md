## 8 部署建议

**保留 Playwright，采用 D（通用能力接口 + 控件驱动）作为默认评测器。** 支持范围限于本轮验证过的界面表达：
- 模态 / 内联 / 富文本编辑器；
- 文字 / 图标关闭控件；
- 原生、隐藏、switch、Element Plus checkbox；
- 磁贴 / 菜单 / 列表形式的建议筛选；
- 卡片 / 表格 / 列表形式的记录；
- 令牌式标签输入；
- 带 describedby 提示或装饰的标签。

理由：
- D 在全部 72 个确认单位上零错误放行、零未知，覆盖完整；
- D 不需要产品标记或按实现写的绑定；
- 冻结后对 6 种新表达无需修改。

H（人工绑定）只建议作为个别实现的临时兜底，因为它的成本随实现数量线性增长。S/V 和框架替换目前没有证据支持。

发布时附带人工复核流程：任何 ADAPTATION_UNKNOWN 都需要人工判断是适配缺口还是产品缺陷，不得改记为通过或失败。

## 9 限制

1. **标签为单评审**：所有标签均由执行者单人确认，没有第二名人工复核。旧材料标签导入自旧 LLM 认证器的见证，经执行者复核。
2. **非盲测**：验收集由编写 D 的同一执行者在冻结后构造，只能称"冻结后的回归验收"。缓解措施是冻结 hash、预先写好的维度计划（`protocol/acceptance-plan.md`）和独立走查认证，但不能排除构造时的无意偏向。
3. **材料都是受控变体**：只来自 4 个 pilot 父本和 2 个 dev 根，每族只改一个维度，缺陷均为注入的单点改动。重复运行不是独立样本，不做总体显著性推断。
4. **验收区分力有限**：B 在验收上的失分全部继承自父本，所以验收集主要证明 D 在冻结后未退化，以及能处理 6 种新表达；它不能证明 D 在"新维度"上优于 B。
5. **视觉义务未经人工核验**：V-HL（K41-O4）全部由自动判据完成，人工复核比例为 0（仅走查截图可供抽查）。
